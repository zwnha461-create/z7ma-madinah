# زحمة المدينة — z7ma-madinah

موقع مؤشر زحمة المدينة المنورة: حالة تقديرية للطرق حول الحرم والمركزية، خريطة حركة حية (خرائط جوجل)، مواقيت صلاة مباشرة، أماكن مشغولة، دليل المركزية والحرم، ومشاركة موقع.

- تشغيل محلي: `npm install` ثم `npm run dev`
- بناء: `npm run build`
- التفاصيل والهندسة العكسية: `REVERSE_ENGINEERING.md`
- المؤشر تقديري بأنماط زمنية — الخريطة وحدها تعرض الحركة الحية الفعلية. بدون حساب وبدون جمع بيانات.
